# 持ち駒カードゲーム（仮）— HTML/JS モック

遊び方は2通り。**普段どおりの1台プレイはサーバ不要**、LAN 対戦のときだけサーバを立てる。

## 1台で遊ぶ（従来どおり・サーバ不要）

`index.html` をダブルクリックして開くだけ（file:// のまま動く。CG-008）。
ローカル2人ホットシート／人間 vs CPU／CPU vs CPU。

## 同じ Wi-Fi の2台で対戦する（LAN 対戦・CG-019）

手札を隠したまま人間同士で対戦できる（権威サーバ型）。npm install は不要。

### ホスト（サーバを立てる側）

1. このフォルダで次のコマンドを1つ実行する:

   ```
   node server.js
   ```

2. 画面に出る「相手に伝える URL」（例: `http://192.168.1.23:8765/`）を相手に伝える。
   自分もその URL（または `http://localhost:8765/`）をブラウザで開く。

3. 先に「参加」した人がホスト（プレイヤー1）になる。ホストはルール設定
   （墓地バッファ・ドロー・後攻の初手・ピッチ持ち越し・先攻1ターン目の攻撃・
   トークンの倒れ先）を選んで「対戦開始」を押す。

- ポートとシードは指定できる: `node server.js --port 8765 --seed 12345`
- Windows でファイアウォールの確認が出たら「プライベートネットワーク」を許可する。

### 相手（もう1台）

伝えられた URL を同じ Wi-Fi のブラウザで開き、「参加」を押して待つだけ。

### 仕組みと記録

- サーバだけが完全な盤面を持ち、各ブラウザには **視点フィルタ（filterStateFor）を
  通した情報だけ**を返す。相手の手札と両者のデッキの中身は通信に一切含まれない。
- 届いた行動はサーバが必ず合法性を検証してから適用する（手番外・非合法手は拒否）。
- 決着すると、サーバが対戦の完全ログ（CG-013 と同じ JSON 形式）を
  `docs/research/playtest_logs/lan/` に書き出し、保存先を画面（標準出力）に表示する。
  解析: `node tools/analyze_logs.js docs/research/playtest_logs/lan/`
- この LAN 対戦は検証用の使い捨て実装（詳細は `docs/DECISION_LOG.md` の CG-019）。
