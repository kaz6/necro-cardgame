# 持ち駒カードゲーム（仮）— HTML/JS モック（v0.3 モック3）

7×7 の盤で、キングだけを置いた空の盤から駒を育てる。**キングを倒したら勝ち。**
倒された駒は倒した側に寝返り、取られた側は山の上から2枚を見て1枚を自分に、1枚を相手に渡す。
モック2では駒が能力（鼓舞・槍衾・威圧・凱歌・裏切り者・遺言・押し出し・不動）を持ち、強さは「基礎＋常時の効果」の実際の強さで比べる。
モック3では能力「運ぶ」（右隣の味方と一緒に動く）・「投げる」（隣の味方を反対側の2マス先へ投げる）と、前線基地（自分のポーンが相手の最奥列にいる間、その周りにも置ける）が加わる。

## 遊び方（サーバ不要）

`index.html` をダブルクリックして開くだけ（file:// のまま動く）。

- 対戦: 人間 対 人間（ホットシート）／人間 対 CPU／CPU 対 CPU
- 駒の頭上の数字は実際の強さ。駒を押すと内訳（基礎＋どの効果でいくつ）が出る（相手の駒も見られる）
- 盤上の自分の駒を押すと動ける先が光る（勝＝取れる／負＝倒される／同＝両方とも山へ／運＝運ぶで隣の味方も一緒に動く）。攻撃先・運ぶの移動先を押すと、確定の前に結果（勝敗・押し出しの連鎖・一緒に動く駒）を盤に出す。もう一度押すか「確定」で指す
- 投げる：投げる駒を押して「投げる」ボタン → 着地点を押すと、確定の前に着地と戦闘の結果を盤に出す
- 手札を押すと置けるマスが光る（丸＝普段の置き場所／紫のひし形＝前線基地で加わった置き場所。前線基地の範囲は常に点線で囲む）
- 寝返った駒の置き場所と、取られた側ドラフトの2択は画面で選ぶ
- 「ルール設定」パネル（畳める）でフラグを切り替える。駒構成（モック3／モック2／モック1）と前線基地のあり・なしもここで切り替える。畳んでいても今の対戦の設定が出る（既定と違う値に★）
- 対戦ログ（設定値・シード・全行動・手数・勝敗）は同じパネルから JSON で保存／コピーできる

## 検証・測定

```
node js/engine.js          # engine のセルフテスト
node js/ai.js              # CPU のセルフテスト
node tools/compare_mock3.js  # モック2／モック3の5列を 500戦ずつ測り、作者の対戦ログの前進度も出して docs/research/ に書き出す（CG-024）
node tools/compare_mock2.js  # モック2の6通り＋モック1の確認列を 500戦ずつ測って docs/research/ に書き出す（CG-023）
node tools/compare_v03.js  # モック1の4通りを 500戦ずつ測って docs/research/ に書き出す（CG-021）
node tools/replay_log.js ログ.json   # 保存した対戦ログを再生して検証する
```
