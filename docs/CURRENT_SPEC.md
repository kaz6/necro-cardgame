## 対戦形式

2人対戦。ターン制。盤面は 3列 × 2段 の6枠。

## ゾーン

- **カードプール**（将来実装）: プレイヤーが事前に選んだカード群
- **デッキ**: プールから作られる山札
- **手札**
- **場**: 3×2 の6枠。前列と後列
- **墓地**: 自分が使える資源置き場
- **ネクロマンサー専用スロット**（6枠とは別）

墓地の定義が重要。**自分の墓地に入るのは、①自分が倒した相手のカード ②相手がコスト支払いで捨てたカード の2つだけ。**
自分のカードは、捨てても倒されても必ず相手の墓地へ行く。自分の墓地に自分のカードは存在しない。

## ネクロマンサー

各プレイヤー1枚。専用スロットに常時公開で置かれる。出し入れ不可。倒されたら敗北。
**これが唯一の勝利条件。**

**体力は 12**（記載日 2026-08-14。★ **これは実装値の転記であり、設計裁定として決めた値ではない。**
CG-017 の測定で分母として現れたためここに控えた。正本は `data/cards.js`。
値を変えるなら裁定として記録すること）

## 初手とドロー

初手は先攻6枚、後攻7枚。毎ターン3枚ドロー（**2026-08-12・CG-010 で 2枚 → 3枚**）。
デッキ切れによる敗北はなし（デッキ枚数は試合の長さの調整弁）。

★ ドロー枚数を上げたのは、ピッチの 1:1 変換（コスト＝捨てる枚数）を変えずに
手札の消費感だけを緩めるため。交換レートは変えていない。
値は `data/cards.js` の `rules.drawPerTurn`。2 に戻せば CG-009 までの挙動に戻る。

## コスト支払い（ピッチコスト制）

マナは存在しない。カードを場に出すには、**手札からカードを捨てる**。

- 捨てたカードのコスト合計が支払いポイントになる
- そのポイントの範囲内で、**手札または自分の墓地から**カードを出せる
- 1:1変換。コスト5を捨てれば、5を1体でも、4と1でも、1を5体でも出せる
- **捨てたカードは相手の墓地へ行く**
- 出せるのは空き枠のみ

手札と自分の墓地は、召喚元として等価に扱う。

**墓地に入ったカードは、入った直後から召喚できる**（更新: 2026-08-14・CG-016 で確定）。
手番のバッファは `rules.graveyardSummonBuffer` でフラグ化されているが、**既定値は 0（＝制限なし）**。
1 は同手番のみ禁止、2 は1手番またぎ。機構そのものは残してあり、
デバッグパネルから 0/1/2 を切り替えて比較できる。
★ 既定を 0 にした理由は DECISION_LOG「墓地バッファの既定値を 0 に確定する（CG-016）」を参照。
墓地にあるのは自分が倒した相手のカードと、相手が支払いで捨てたカードだけなので、
**墓地からの召喚は常に「奪ったものを使役する」行為になる**。

## 前列・後列

後列のカードは、同じ列の前列が残っている間は攻撃されない。
攻撃は前列・後列どちらからでも可能。配置換えは可能（コストは未確定）。

## 戦闘と死

倒したカードは**自分の墓地**へ入り、以後は自分の資源になる。
体力は回復しない（受けたダメージは残り続ける）。

## 墓地の総コスト

各プレイヤーの墓地にあるカードのコスト合計を、常時表示する。
**プロトでは表示のみで、ゲーム効果は持たせない。** 数値の推移を観測してから、何を紐付けるか決める。

## カード能力（更新: 2026-08-11）

カード8種のうち4種が能力を持つ。**4種とも一貫法則の内側で動き、法則に例外を作らない。**

| id | 数値 | 効果 |
|---|---|---|
| c05 | 2コスト 1/2 | 倒されたとき、1/1 になって後列へ移動する |
| c06 | 3コスト 2/3 | 場に出たとき、右の空き枠に 1/1 のトークンを出す |
| c07 | 4コスト 4/2 | 相手のカードを倒したとき、相手のデッキの一番上1枚を自分の墓地へ送る |
| c08 | 4コスト 2/5 | 呪い。相手の墓地にある間、相手が墓地から召喚する最初の1回に、支払いポイントを1多く必要とする |

**効果テキストに書かれていない部分の裁定**（`data/cards.js` の `rules.abilities` でフラグ化）:

- **c05 の後列に空きがない場合 → 不発。通常どおり相手の墓地へ**（`deathRetreatNoRoom`）
- **c05 の退避先は同じ列の後列を優先し、埋まっていれば後列を左から**（`deathRetreatSlotOrder`）
- **c07 は反撃で倒したときも発動する**（`killTriggerOnCounterattack`）
- **c08 が複数あるときは加算し、その召喚でまとめて全部発動する**（`curseStacking`）

その他:

- c05 が退避しても「倒された」事実は残る（c07 の効果は乗る）。墓地に入った時点で刷られた数値に戻り、退避権も戻る
- c06 のトークンは `data/cards.js` の `tokens` に定義。デッキには入らない。持ち主は出した側。
  **★ 倒されると相手の墓地へは行かず、その場で消滅する**（更新: 2026-08-11・CG-007。
  `tokens.list[].onDeath`）。コスト0のため 0pt で再召喚でき、CPU 同士1000戦で全召喚の 91.7% が
  これになって150戦が未決着になったため。**一貫法則の例外ではない**（トークンはカードとして
  手札に存在しないので、そもそも手札を離れていない）
- c07 がネクロマンサーを倒した場合は勝敗が決するので解決しない
- c08 の「最初の1回」はそのカードが相手の墓地に入ってから数える。墓地から出て入り直せば数え直す
- デッキ構成: c08 は2枚投入。減らした1枚は c07 に回してある（コスト4の総枚数は不変）
