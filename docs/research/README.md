# research/

## 用途

この企画の**調査・市場リサーチ・先行事例分析**を格納する。

ゲーム機構そのものの決定は `../DECISION_LOG.md`、却下案は `../REJECTED.md` が持つ。
ここに置くのは、その判断の**材料**となる調べもの。

---

## ファイル名規則

```
調査内容_YYYYMMDD.md
```

例:
- `持ち駒系カードゲーム先行事例_20260811.md`
- `蘇生メカニクス市場調査_20260815.md`

---

## 記載ルール

- **冒頭に必ず TL;DR と調査日を書く。**

  ```markdown
  # 持ち駒系カードゲーム先行事例

  調査日: 2026-08-11

  ## TL;DR
  - （3行程度で結論）
  ```

- 設計判断が出た場合は、`../DECISION_LOG.md` 側に**根拠としてこのファイルへの
  相対リンクを張る**。

  ```markdown
  # 2026-08-11｜（決定タイトル）

  根拠: [持ち駒系カードゲーム先行事例](research/持ち駒系カードゲーム先行事例_20260811.md)
  ```

  リンクは DECISION_LOG 側から research 側へ張る。逆方向は必須ではない。

---

## 正本について

**正本は Notion の「参照資料（調査・先行事例）」ページ。**

`docs/research/` はその **AI 可読ミラーであり読み取り専用**。

- ここのファイルを編集して調査内容を更新しない。更新は Notion 側で行う。
- Notion と食い違った場合、**Notion が正しい**。ミラー側を直す。
