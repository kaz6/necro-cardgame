# REJECTED（却下案索引）

> **正本は Notion の「却下案索引」ページ。これはその AI 可読ミラー。**
> 目的: 将来の自分や AI が蒸し返さないよう、却下した案を理由とともに残す。

ステータスの意味:

- **死んだ案** — 理由が構造的で、覆る見込みがない。再提案しない
- **保留（種）** — 理由が時期・前提に依存する。条件が変われば復活の目がある
- **消滅** — 保留ですらなく削除

再提案する場合は、**「なぜ却下理由が変わったか」を先に述べること。**

# 2026-08-11 時点

**共有の山からドロー**
全員が同じ泉から引くと、奪われても代わりが同じ場所から出てくる。自分のものを失った痛みが消え、検証したい仮説そのものが立たなくなる。
→ **死んだ案**

**両者の墓地からドロー**
ネクロマンサー設定には最も合うが、墓地を「誰が何を失ったかの記録装置」として機能させたい。引き先にすると第二のデッキになる。
→ **保留（種）**。蘇生手段を増やす段になれば復活の価値あり

**死んだカードが強化される**
倒した側が +1 ではなく +1.5 を得ることになり、ポジティブフィードバックが過剰。リードした側が加速して逆転不能になる。
→ **保留（種）**。維持コストや、一度使うと消滅する枷とセットなら復活の目あり

**呪いの「奪取トリガー型」（奪われた瞬間に発動）**
相手が倒さなければ一生発動しない。回避可能な脅威は盤面に置いた瞬間から無視される置物になる。
→ **死んだ案**。墓地常在型を採用

**墓地送りコスト2枚**
1枚起こすたびに相手の選択肢が2つ増えると取引レートが赤字になり、蘇生が明らかに損な行動になる。ジレンマは等価交換の近傍でしか生まれない。
→ **1:1 で固定**。重すぎる場合は回数制限を動かす

**デッキ／カードプールの途中補充**
「デッキ枚数＝残り時間」の時計が止まり、蘇生コストが痛くなくなる。
→ **保留（種）**。時計を止めるのではなく、代償を払って巻き戻す形なら生き残る

**勝利条件＝相手カードを全て墓地送り**
奪う行為が勝利に直結し、snowball が不可避。将棋が破綻しないのは駒得ではなく詰みが勝利だからで、「速度」が「量」に対抗できる軸として残っている。
→ **死んだ案**

**盤面なし・同時公開型（戦争＋持ち駒）**
奪い返しの循環とターゲット選択が成立しない。
→ **死んだ案**（Claude の推奨を撤回）

**初回プロトへのデッキ構築導入**
面白くなかった場合の原因が「デッキが悪い」なのか「機構が面白くない」なのか切り分け不能になる。
→ **保留**。プール選択→ランダムデッキ化の案は有望（KeyForge 型）なので段階2以降で復活させる

**ネクロマンサーの出し入れ・離脱**
判断がかったるくなり、実装も増える。
→ **消滅**（保留ではなく削除）

**「詰みにつながる行いはできない」ルール**
将棋でこれが成立するのは完全情報だから。カードゲームには相手の手札・デッキがあり、自殺手判定が不可能。
→ **禁止しない。やったら負けるだけ**

# 2026-08-11 追記（基礎ルール再構築に伴う）

**マナ制**
ピッチコスト制に置き換え。マナはこの企画の核（手を離れたものが相手の資源になる）と無関係だった。
→ **死んだ案**

**同等コストのカード1枚を捨てて召喚**
コスト3を出すのもコスト1を出すのも消費1枚になり、常に高コストを出すのが正解になる。低コストカードが存在意義を失う。
→ **死んだ案**。コスト＝捨てるコスト合計へ

**2枚ドラフト**
墓地を肥やす役割をピッチコストが完全に代替したため、現行のターン内ドローとしては判断コストだけが残る。
→ **保留（種）**。ターン内ドローとしては廃止だが、別枠での復活を想定する。
候補はカードプール→デッキ作成の工程（下記項目とセットで検討）

**デッキ切れ敗北（デッキ枚数＝残り時間）**
ピッチコストで手札消費が激増し、時計として速すぎる。圧縮対策としての役割も不要になった。
→ **死んだ案**（前の確定事項を撤回）

**持ち駒ゾーン（公開・即打てる別ゾーン）**
ゾーンが3つになって参照先が多すぎ、墓地分離ルールとも矛盾していた。
→ **死んだ案**（前の確定事項を撤回）

**倒したカードを即座に自分の場へ置き直す**
倒す→即再展開→また倒すでリードした側が一方的に加速する。
→ **基本ルールとしては却下。固有効果としては有望**

**裏置き（罠モンスター）**
奪う対象が見えなくなり、「あのカードを奪えば一気に逆転できる」というターゲット選択を弱める。
→ **保留（種）**

**二度死ぬ（持ち駒として倒されて初めて墓地へ）**
ピッチコストが死体供給を解決したため不要になった。
→ **保留（種）**。snowball が観測されたら復活させる

**スキルカード（モンスター以外のカード種別）**
モンスターのみに絞る。スキルカードは倒されて奪われる対象にならず、核の外側に出る。
→ **保留**

**連続攻撃効果（単体での採用）**
倒した数だけ資源が増え、snowball を強める。
→ **制限とセットの場合のみ可**

**カードプール→デッキ作成の一捻り**
やりたいが、「奪い奪い返し合う」の検証が先。
→ **保留（種）**。検証完了後に着手。ドラフトをここで復活させる案あり

**独立世界（共有世界に属さない）**
設定が味方にならない。カスケード後のif世界に属させれば、
認可体系の崩壊と埋葬作法への冒涜が、そのまま話の燃料に変わる。
→ **死んだ案**

**正史の世界（現在時制）に属させる**
ネクロマンサーが魔法＝アクセス権モデルに収まらず、魔法使い（怪異レベル）扱いにするしかない。
格の高い存在同士の戦いになり、企画のトーンが変わりすぎる。
→ **死んだ案**

**プロト段階で既存企画のキャラクターに名前を付ける**
遠征ギルドログ本編で彼らがどう死ぬか（あるいは死なないか）が未確定のうちに死体として扱うと、
後で衝突する。
→ **本編完成まで凍結**。プロトの8種はモンスターA〜H

**超常怪異のカード化**
物理干渉不可・法外の存在であり、倒して奪う対象にならない。核と両立しない。
→ **死んだ案**（怪異以下は全てカード化可）
