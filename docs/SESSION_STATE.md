### 要裁定 1: CG-006 — トークンの 0pt 再召喚に歯止めを入れるか

**日時:** 2026-08-11 22:31 JST
**タスクページ:** CG-006（`_tasks（実装タスク）` 配下）
**書いた節:** 実装結果

**論点:** CPU はトークンの 0pt 再召喚を全召喚の 91.7%（259435 / 282897 回）に使い、
1000戦中 150戦が未決着（ターン上限300）になった。歯止めを入れるか。

**A（推奨）: トークンを墓地へ送らず消滅させる**（`data/cards.json` の `tokens` 側で切る）。
トークン1枚が両者の墓地を往復し続けて盤面が空かないため、
**相手の場が空でないとネクロマンサーを殴れない**ルールと噛み合って決着条件が消えている。
ピッチを1枚も払わずに盤面を埋め続けられる手が存在すること自体が、ピッチコスト制の外側にある。

**B: 何もしない。** 人間はここまで機械的に往復させないので、実害はプレイテストで見てから判断する。

**トレードオフ:** A＝抜け道は消えるが「倒したカードは相手の資源になる」の例外を1つ作る。
B＝例外を作らずに済むが、CPU 対戦と自動計測が当面まともに測れない
（埋まり率 67.4% はほぼこの抜け道の産物で、他の指標も引きずられている）。

**却下済み:** なし。ただし CG-005 の DECISION_LOG に
「トークンのコストは0の直接の帰結として意図的に残す。歯止めが要ると判断した場合は
`tokens` の定義側で変える（engine は触らない）」と明記済み。A はその手順に沿う。

### 要裁定 2: CG-006 — 盤面の厚みは AI 由来ではなかった。仕様を触るか

**日時:** 2026-08-11 22:31 JST
**タスクページ:** CG-006
**書いた節:** 実装結果

**論点:** 抜け道を除いた CPU でも平均埋まり率は 26.8% → 28.3%（+1.5pt）どまりで、
**ターン6以降は両者とも約2.0/6枠に収束する**。CG-005 の裁定が保留した
「ランダムAIの性質かもしれない」は否定された。仕様を触るか。

**A（推奨）: ピッチの交換レートを緩める**（例: ピッチ1枚あたりの pt を上げる、
または召喚時のピッチを1枚固定にする）。
現状は **1体出すのに手札2枚**（ピッチ1〜2枚＋出す1枚）を消費するのに対し、
供給は毎ターン2枚。**盤面を維持しながら増やす余地が構造的に存在しない。**
盤面枠を減らす案より、供給側を触るほうが「前後列の判断」を残せる。

**B: 何もせず、人間2人のプレイテストへ進む。**
2.0/6枠でも人間には十分な判断量かもしれず、いま触ると二重に調整することになる。

**トレードオフ:** A＝前後列の判断が発生する水準まで持っていけるが、
テンポと試合の長さが一緒に動くので測り直しが要る。
B＝調整の焼き込みを避けられるが、前後列の仕組みが働かないまま人間に見せることになる。

**却下済み:** なし（この論点に該当する却下案はない）。

### 要裁定 3: CG-006 — 「墓地からの召喚＝奪ったものを使役する」の表現が実態と合っていない

**日時:** 2026-08-11 22:31 JST
**タスクページ:** CG-006
**書いた節:** 実装結果

**論点:** 相手に渡ったカードが**相手の場で倒される**と、倒した側＝元の持ち主の墓地へ入る（里帰り）。
このとき墓地からの召喚は「自分のカードを自分で蘇生する」になる。
ランダムAI 1000戦で 5449 回、CPU で 142905 回発生している。

**A（推奨）: 表現を直す。** 挙動は一貫法則どおりで正しいので、
`data/cards.json` の `_summonSource` と engine のコメントにある
「墓地からの召喚は**常に**『奪ったものを使役する』行為になる」を、
「奪ったもの、または一度奪われて奪い返したもの」に直す。

**B: 仕様を変える。** 里帰りを禁止し、元の持ち主の墓地には戻さない（＝一貫法則に例外を作る）。

**トレードオフ:** A＝ルールは1つも変わらないが、企画の説明の「常に」が1つ弱くなる。
B＝説明は保たれるが、「自分の手を離れたカードは必ず相手の墓地へ」に例外が入る。

**却下済み:** なし。

★ 付随: `js/engine.js` のセルフテストは
「自分の墓地に自分のカードが存在しない（一貫法則）」を不変条件として検査しているが、
**これは短い試合でしか成り立たない**（現在のテストは通っているが、たまたま通っている）。
A を採る場合はこの検査も直す必要がある。**engine は今回触っていない。**
