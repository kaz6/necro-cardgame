### 要裁定 3: CG-006 — 「墓地からの召喚＝奪ったものを使役する」の表現が実態と合っていない

**日時:** 2026-08-11 22:31 JST
**タスクページ:** CG-006
**書いた節:** 実装結果

**論点:** 相手に渡ったカードが**相手の場で倒される**と、倒した側＝元の持ち主の墓地へ入る（里帰り）。
このとき墓地からの召喚は「自分のカードを自分で蘇生する」になる。
ランダムAI 1000戦で 5449 回、CPU で 142905 回発生している。

**A（推奨）: 表現を直す。** 挙動は一貫法則どおりで正しいので、
`data/cards.js` の `_summonSource` と engine のコメントにある
「墓地からの召喚は**常に**『奪ったものを使役する』行為になる」を、
「奪ったもの、または一度奪われて奪い返したもの」に直す。

**B: 仕様を変える。** 里帰りを禁止し、元の持ち主の墓地には戻さない（＝一貫法則に例外を作る）。

**トレードオフ:** A＝ルールは1つも変わらないが、企画の説明の「常に」が1つ弱くなる。
B＝説明は保たれるが、「自分の手を離れたカードは必ず相手の墓地へ」に例外が入る。

**却下済み:** なし。

★ 付随: `js/engine.js` のセルフテストは
「自分の墓地に自分のカードが存在しない（一貫法則）」を不変条件として検査しているが、
**これは短い試合でしか成り立たない**（現在のテストは通っているが、たまたま通っている）。
A を採る場合はこの検査も直す必要がある。**engine は今回触っていない。**

### 要裁定 5: CG-013 — 解析指標の操作的定義の追認

**日時:** 2026-08-12 23:30 JST
**タスクページ:** CG-013（指示ブロックで実施）

**論点:** 指示の言葉のままでは数えられない4つの指標を、観測可能な形に定義して実装した。
