## 未確定項目

**勝手に確定させないこと。** ここにある項目は人間の判断待ち。

### ⚠️ 最優先: 召喚元の墓地はどちらか（正本の矛盾）

`CURRENT_SPEC` 内で記述が食い違っている。

- 「そのポイントの範囲内で、**手札または相手の墓地から**カードを出せる」
  「手札と相手の墓地は、召喚元として等価に扱う」
- 一方で「墓地: **自分が使える**資源置き場」
  「倒したカードは**自分の墓地**へ入り、以後は**自分の資源**になる」
  「自分の墓地に入るのは ①自分が倒した相手のカード ②相手が支払いで捨てたカード」

前者を採ると、自分がピッチしたカードは相手の墓地に置かれた上で**自分だけが**再利用でき、
相手はそれを使えない。一貫法則「手を離れたカードは相手の資源になる」と噛み合わない。
後者を採ると「相手の墓地から」の記述が誤りになる。

**現状: 正本の明文どおり `opponentGraveyard` を既定にしてある。**
`data/cards.json` の `rules.summonSource` を `"ownGraveyard"` に変えれば
もう一方の読みで動く（engine・UI とも対応済み、セルフテストで両方の動作を確認済み）。
